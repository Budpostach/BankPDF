# BankPDF Converter 🇺🇦

Професійне клієнтське веб-решення для підготовки, оптимізації та стиснення PDF-документів під суворі вимоги банків України (жорсткий ліміт розміру **< 490 КБ**).

🌐 **Live Demo:** [https://budpostach.github.io/BankPDF/](https://budpostach.github.io/BankPDF/)
 
---

## 🚀 Основні можливості

* **Строгий контроль розміру (< 490 КБ):** Автоматичний підбір ступеня стиснення для гарантованого проходження банківських лімітів.
* **Smart DPI (Розумна роздільна здатність):** 
  * Для коротких документів (1-2 сторінки) застосовується висока деталізація до **300 DPI**.
  * Для багатосторінкових файлів та каталогів використовується каскадна ієрархія якості з роздільною здатністю **від 600 до 150 DPI**.
* **Автоматичне розбиття (Split):** Якщо документ складається з великої кількості сторінок і його обсяг перевищує ліміт, система автоматично розбиває його на окремі сторінки, стискає кожну з них до вимог **< 490 КБ** та пакує в зручний **ZIP-архив**.
* **Grayscale (8-bit):** Конвертація кольорових сканів у чорно-білий формат для максимального зменшення розміру файлу без втрати читабельності тексту.
* **Повна безпека (Client-Side):** Вся обробка документів відбувається **виключно у вашому браузері** за допомогою JavaScript. Конфіденційні дані, контракти та інвойси нікуди не завантажуються на сторонні сервери.
* **Мультивімовність:** Інтерфейс підтримує українську та англійську мови (`UA` / `EN`).
* **Попередній перегляд:** Можливість візуально порівняти оригінальну сторінку з результатами обробки перед завантаженням.

## 🛠 Технологічний стек

Проєкт створений як швидкий і легкий статичний веб-додаток (Vanilla JS + Tailwind CSS):
* **Tailwind CSS** — сучасний адаптивний дизайн інтерфейсу.
* **PDF.js** — рендеринг та розбір PDF-сторінок на стороні клієнта.
* **jsPDF** — генерація та збірка оптимізованих PDF-файлів.
* **JSZip** — упаковка багатосторінкових експортів у ZIP-архіви.
* **Lucide Icons** — мінімалістичні іконки інтерфейсу.
